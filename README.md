# Ngwisa gong gallery

Headless Wix storefront + Ngwisa Studio admin.

- `Ngwisa Site Deploy.dc.html`: site entry. Shop on `/`, Studio on `/studio` (or `#studio`).
- `Ngwisa Studio.dc.html`: owner-only admin (site copy, media slots, New in, pairs, appearances, worn by you, size guide, Media Manager).
- `ngwisa-wix.js`: Wix REST client (Stores, Cart, Checkout, Data, Media).
- Products, prices, stock and product photos come from Wix Stores.

See `Ngwisa Studio Wix Setup.md` for collections and permissions.
